# Finance Tracker Codex Instructions

## Explicit Authorization Required

Do not create, edit, move, delete, format, stage, commit, push, or otherwise
change any project file or external system unless the user explicitly asks for
that specific change.

Requests to inspect, explain, review, diagnose, plan, discuss next steps, or
"get started" authorize read-only work only. Before making changes, obtain an
explicit implementation request from the user. Do not infer permission to
implement from context, a previously discussed plan, or the existence of a
recorded next task.

Before beginning project work, read `docs/PROJECT_SOURCE.md`, especially its
latest dated update and current checkpoint.

After completing and verifying meaningful project work, append a dated progress
entry to `docs/PROJECT_SOURCE.md` following its **Codex Continuity** convention.
Preserve earlier entries as project history.
